# MovieExplorer

A beginner-friendly React movie and TV show explorer built with the TVMaze API.

## Features

- Home page with hero section
- Movie listing page
- Search movies and TV shows
- Movie cards
- Movie details modal
- Responsive design

## Run the project

```bash
npm install
npm run dev
```

## API

- `https://api.tvmaze.com/shows`
- `https://api.tvmaze.com/search/shows?q=QUERY`
